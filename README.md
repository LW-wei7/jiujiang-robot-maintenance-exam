## 使用

- 顺序刷题、专项随机、随机30题、逐题解析、错题本、收藏、高频错题、答题卡、成绩记录与深浅色主题。
- 选择/判断练习点击后立即按题源判分，锁定选项并显示学习解析；考试模式交卷前不显示答案。
- 90分钟模拟抽90题（70选择+20判断）；快速模拟30题25分钟（23选择+7判断）。每题1分，比例按源题型占比取整。这是备赛设置，正式题量以比赛现场试卷为准。
- 学习解析为备赛辅助生成，不是主办方官方解析。201条已撰写通用学习解析，158条标记`needs_review`并说明具体疑点。所有题仍以原始`source_answer`判分，不擅自更正主办方答案。
- 选择11保留4幅原WMF转换公式，但原稿缺题干图；45原机构图完整；56原稿缺图及全部选项。

## 离线与更新

直接打开`index.html`即可答题，请保留同目录脚本、样式、图标和`assets/questions/`。本地HTTP验收可在项目目录运行`python -m http.server 8080`，然后打开`http://localhost:8080/`。

通过HTTPS或localhost访问会注册Service Worker。首次联网完成“离线资源已准备好”后可离线刷新；PWA安装入口取决于浏览器。检测到新版后，先结束答题或返回首页，再点“更新到新版”。

缓存版本：`robot-exam-official-202609-v1`。缓存HTML、脚本、样式、两份JSON、图标及全部5幅题目图片；仅清理本项目旧缓存中的本项目资源，保留其他项目缓存。

学习记录采用`jj_robot_official_202609_`前缀的wrong、fav、history、stats四个独立键。旧版学习数据不读取、不映射、不删除。主题使用独立共享偏好键。记录仅存在当前浏览器；隐私模式或存储限制可能使其无法持久保存。

## 数据与核对

- `questions.json`是活动题库，内嵌`BANK`为相同数据的文件直开副本；`explanations.json`以字符串ID关联。
- `assets/questions/`只放从本次原稿提取或转换的图片；不重绘、不猜图。
- [题库导入报告](题库导入报告.md)、[题源疑点清单](题源疑点清单.md)记录原稿问题和导入边界；不由网页加载。
- [验收结果](验收结果.md)记录实际测试与限制。原DOCX、原始解包和备份不发布。
- 运行层不再包含旧题源或旧数据fallback，历史版本可从Git历史恢复。修改前提交`1a626729ff70f4c375e2e0bd43215370e40ec494`，完整修改前工作区另有本地备份。

## 发布

同一仓库`LW-wei7/jiujiang-robot-maintenance-exam`的main分支由`.github/workflows/pages.yml`部署。构建仅复制运行文件及图片目录，不上传题源DOCX、审计临时目录或本地学习记录。

修改题库时先核对源编号、答案、图片和重复组，再同步JSON与内嵌BANK，升级缓存版本，完成真实HTTP、旧缓存升级、手机尺寸、Edge与离线验证后发布。
