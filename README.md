# 九江工业机器人系统运维模拟考试

V4（2026-09-09），面向手机的静态备赛练习网页。原PDF全部680条记录已映射到600道去重题目：381单选、60多选、159判断。584题可计分，16题因缺项、截断或明显歧义仅供核对。

## 使用规则

- 标准模拟：90 分钟，50 单选 + 10 多选 + 30 判断，共 100 分。
- 快速模拟：30 题、25 分钟；满分按所抽题型计算。
- 单选和判断每题 1 分，多选每题 2 分且全对才得分。练习中的多选需点击“确认答案”后才判分。
- 答题卡区分已提交、待确认和空白题；提前交卷有未提交提醒。
- 记录保存在当前浏览器的 localStorage，不主动上传答题数据，没有跨设备同步。清理站点数据会丢失记录。
- 当前未完成试卷不支持刷新后恢复。成绩仅在结束考试或练习时保存。

## 内容说明

本网页用于备赛练习，不是赛事官方试卷或官方逐题解析。已对照用户提供的《工业机器人运维员--振兴杯--技术工作文件(含知识题库)》逐条核对转录；每题附PDF物理页、印刷页、原题号。优先级沿用原包。

本版合并23条旧版重复记录，补录单选第149题（现#623，原文件D列空白，暂不计分），清除18处原题干答案字母，清理60组重复选项字母前缀，并补全#426跨页遗漏的题干。GPS旧#285/#460合并到#277。同内容、不同干扰项的题在一张试卷中不重复抽取。

勘误答案：#271 B→D（插补）、#279 A→C（电容测距）、#298 A→B（普通真空吸盘接触面）、#349 C→A（RobotStudio X轴颜色）。作答前隐藏答案和勘误内容；作答后展示原答案、勘误理由及厂商资料链接。这些是有资料支持的备赛勘误，不代表主办方正式更正。

16道待核对题保留在首页独立入口，禁用选择和评分，不计成绩或错次。其余题目的专业原理解析仍未全部验证；“已对照PDF”只表示转录核对，不等于确认原题库没有专业错误。

旧错题、收藏按题号映射合并，错次累加且不会因再次刷新重复累加。历史成绩保留当时结果；旧版没有保存逐项作答记录，无法按勘误后答案重新计算历史成绩。存储仅在同一浏览器、同一站点范围内继承。

设备操作应依据适用型号的官方手册和现场规程，不能直接套用题库描述。

## 离线与安装

通过 HTTPS 打开一次，等页面提示离线资源准备完成后，可在断网状态继续答题。支持的浏览器可安装 PWA；iPhone 使用 Safari 分享菜单中的“添加到主屏幕”。首次访问需要联网。

试卷、答案和解析全部包含在静态文件中。本仓库和网站一旦公开，访问者可读取这些内容。答题记录仍只保存在各自的浏览器。

## GitHub Pages

在仓库 Settings → Pages 中选择 GitHub Actions 作为发布源。工作流由 main 分支 push 或 workflow_dispatch 触发，使用 GitHub 官方 Pages Actions。

网页部署只打包明确列出的运行文件；README、Git 配置及工作流不会作为网页目录发布。仓库本身仍可展示已提交的 README 和工作流。

不需要 React、Vite、Node 构建链或 Jekyll。开发时可在项目目录运行：

```shell
python -m http.server 8080 --bind 127.0.0.1
```

访问本机 localhost 的 8080 端口。题库已内嵌在HTML；修改题库时务必同步questions.json、HTML和explanations.json，并更新sw.js缓存版本。V4以后发现更新会提示按钮，只能在结束答题后更新。V3升级首次需要联网打开，关闭该站点的全部旧标签页/PWA窗口，再重新打开，确认顶部显示V4。

直接使用文件版时，请完整解压新版并打开其中的index.html；U盘上的V3文件不会因网站更新自动改变。无需清理浏览器站点数据。
